# Phase 2 Notes

Implemented in this increment:

- Clubs/Guilds backend and Mini App screen.
- Club owner/officer roles.
- Club privacy modes and join requests.
- Membership limits.
- Single-elimination tournaments for 4/8/16 players.
- Seeded first-round bracket generation.
- Authorized match result reporting.
- Automatic round advancement and elimination tracking.
- Tournament/club API router registration.
- Alembic migration.

Not implemented yet:

- Automatic tournament match creation from the live GameService.
- Telegram Stars payments.
- Gems/Battle Pass/VIP.
- Full spectator mode.
- Advanced multi-player Hokm rules.
- 3D rendering/audio/card art.

This is intentionally a real incremental implementation rather than a claim that the entire 200-item blueprint is complete.
